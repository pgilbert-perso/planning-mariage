Configuration initiale (une seule fois)

Ce fichier a besoin d'une base Firebase gratuite (chez Google) pour synchroniser les données entre tout le monde, sans qu'aucun invité n'ait besoin d'un compte.

  1. Allez sur console.firebase.google.com, connectez-vous, créez un projet gratuit (plan "Spark").
  2. Dans le projet : Build → Firestore Database → créer une base, mode "test" pour commencer.
  3. Dans Build → Authentication → Sign-in method, activez Anonyme.
  4. Dans Paramètres du projet → Vos applications, créez une appli Web, copiez l'objet firebaseConfig.
  5. Collez-le dans ce fichier à la place du bloc marqué À REMPLACER (tout en haut du deuxième <script>), enregistrez, puis rechargez cette page.

Une fois configuré, hébergez ce fichier (GitHub Pages, Netlify, ou votre hébergeur habituel) et partagez le lien — aucune connexion n'est demandée à vos invités.
